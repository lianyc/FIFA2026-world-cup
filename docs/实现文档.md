# FIFA World Cup 2026 赛程可视化 — 实现文档

## 项目概述

2026 美加墨世界杯赛程可视化前端应用。支持小组赛积分榜、淘汰赛晋级拓扑、全部比赛时间线三个视图，数据来自外部 API 自动更新。

## 技术栈

| 层 | 选型 |
|---|------|
| 框架 | Vue 3.5 (Composition API, `<script lang='ts' setup>`) |
| 语言 | TypeScript 5.6 |
| 构建 | Vite 6 |
| 路由 | Vue Router 4 |
| 状态管理 | Pinia 2 |
| UI 组件库 | Element Plus 2.9 |
| 数据源 | fixturedownload.com (免费 JSON API) |

## 项目结构

src/

## 数据流

```
fixturedownload.com (JSON API)
        │
        ▼
  vite.config.ts proxy: /api/fixtures → 外部 API (开发环境免除 CORS)
        │
        ▼
  worldcup2026.ts: fetchMatchesFromApi()
        │  ┌─ 成功 → 104 场比赛 JSON → 转换为 Match[]
        │  └─ 失败 → buildFallbackMatches() 生成本地降级数据
        ▼
  matches.ts (Pinia Store): loadApiData()
        │  ┌─ 合并 localStorage 中已有的 matchResults (用户手动录入优先)
        │  └─ 合并 localStorage 中已有的 knockoutTeams
        ▼
  所有页面直接使用 store.matches / store.groupStage / store.standings
```

## 赛制

- **48 支球队**，分 12 组 (A-L)，每组 4 队
- **小组赛**：每组 6 场 × 12 组 = 72 场 (2026-06-11 ~ 06-28)
- **淘汰赛**：32 强 → 16 强 → 8 强 → 半决赛 → 三四名 → 决赛 (06-28 ~ 07-19)
- 晋级规则：每组前 2 名 + 8 支成绩最好的第 3 名 = 32 强
- 所有时间使用北京时间 (UTC+8)

## 淘汰赛自动晋级逻辑

1. 某组 6 场小组赛全部录入比分 → 取积分榜前两名 → 自动填入对应 32 强席位
2. 淘汰赛每轮结果出来 → 胜者自动填入下一轮对阵
3. `resolveSource()` 解析 `sourceHome`/`sourceAway`：
   - `"1A"` = A 组第 1, `"2B"` = B 组第 2
   - `"W73"` = 73 号比赛胜者, `"L101"` = 101 号比赛负者
   - `"3ABCDF"` = 跨组第 3 名 (暂未实现自动计算)

## 数据持久化

- `localStorage['fifa2026-results']` — 用户手动录入的比分 (Map<matchId, {homeScore, awayScore}>)
- `localStorage['fifa2026-koTeams']` — 淘汰赛自动晋级后填入的球队
- API 返回比分后自动 merge，localStorage 数据优先级更高
